Connect GTM AI to Binance Futures

The panel signs every order in your browser with your secret key. Binance does not accept orders straight from a web page, so the signed order goes through a small relay that you own. The relay cannot change an order and never sees your secret key.

Watch only: see your Binance / TradingView trades on the panel

  1. binance.com → API Management → Create API → tick only Enable Reading (no trading, no withdrawals).
  2. On the GTM AI page open the Binance Futures box: Watch only, REAL account, paste the API key and secret, press Connect. No relay is needed.
  3. Press START. The panel opens in LIVE with the agents paused and shows every USDT-M futures position with its SL / TP. Closed trades go to HISTORY (replay), the journal and the Data Analyzer; the last 30 days are loaded from Binance.
  4. To trade from TradingView: TradingView → Trading Panel → Binance → Connect. Trades you place there appear on the panel within a few seconds.
සිංහලෙන්: TradingView එකෙන් Binance එකට trade දාලා, ඒවා GTM AI panel එකේ බලන්න Watch only තෝරන්න. API key එකේ Enable Reading විතරක් tick කරන්න. Relay එකක් ඕනේ නෑ. Panel එක කිසිම order එකක් යවන්නේ නෑ.

1. Make an API key (start with practice money)

  1. Testnet: open testnet.binancefuture.com, log in, open the API Key tab and copy the API key and the secret key. — or —
  2. Demo trading: binance.com → Futures → Demo Trading → API Management → create a key.
  3. Real account (later): binance.com → API Management → Create API. Tick Enable Futures only. Never tick withdrawals. You can restrict the key to your relay's IP address.
සිංහලෙන්: මුලින්ම Testnet එකේ key එකක් හදන්න (බොරු සල්ලි). Real account එකේ key එකක් හදනවා නම් Enable Futures විතරක් tick කරන්න. Withdraw කිසිම වෙලාවක enable කරන්න එපා.

2. Trade mode only: make your relay (pick one, both are free)

A) Cloudflare Worker — works 24/7, also from a phone

  1. Make a free account at dash.cloudflare.com.
  2. Workers & Pages → Create → Worker, give it a name (for example gtm-relay) and press Deploy.
  3. Press Edit code, delete what is there and paste binance-relay-worker.js. Press Deploy.
  4. Copy the address, for example https://gtm-relay.yourname.workers.dev.

B) relay.py on your own computer — no account needed

  1. Install Python 3 from python.org (tick "Add to PATH").
  2. Download relay.py and double-click it (or run python relay.py). Keep the window open.
  3. The address is http://127.0.0.1:8787. If Chrome asks to allow access to your local network, press Allow.
සිංහලෙන්: Relay එක කියන්නේ ඔබේ order එක Binance එකට යවන පොඩි "තැපැල්කරුවෙක්". A) Cloudflare Worker එක පැය 24ම වැඩ කරනවා. B) relay.py ඔබේ PC එකේ දුවනවා, PC එක on වෙලා තියෙන්න ඕනේ. දෙකම free.

3. Trade mode: connect on the GTM AI page

  1. Open the Binance Futures box above the panel. Choose Trade and Testnet, paste the API key, the secret key and the relay address.
  2. Leave Hedge mode on if you want long and short on the same coin at the same time. Set the leverage.
  3. Press Connect. The box shows your USDT balance.
  4. Press START on the panel, add crypto symbols (BTCUSD = BTCUSDT) on SETTINGS, set their entry setups, then press SIMULATOR → LIVE at the top right and confirm.
  5. Keep the tab open: new entries, break-even and trailing run in the page. SL and TP are real Binance orders, so they stay even if you close it.
